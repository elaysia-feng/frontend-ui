# 项目约定

- **语言**：本项目新增代码一律用 **TypeScript**，不要用 Python（用户明确要求）。交付物 `frontend-ui.html` 是浏览器产物，内嵌的是类型擦除后的 JS。
- **形态**：保持单文件、零依赖、双击即用；不要拆成多文件站点或引入 npm 运行时依赖。
- **构建**：`build_pages.ts` 是唯一生成器，`node build_pages.ts` / `npm run build`；脚本幂等，只替换 `PT:` 标记区块，不动原有 391 个组件卡片。
- **技术环境**：Node v22.22.2，原生 TS 类型擦除可用（无需 tsc/tsx）。
- **结构**：组件库视图（391 卡片 + 搜索/分类 + Prompt/代码弹窗）与页面模板视图（6 大业务场景 × 4 个整页模板 + 全屏预览）通过顶部 viewbar 切换。
- **视觉基调**：用户明确要求「高级感」。低饱和配色、克制的圆角/阴影/字重、单色几何图标、中性底 + 衬线展示标题；新增模板不要引入高饱和大渐变或彩色 emoji，统一由 `polishCss / polishText / REFINE_CSS` 处理。
