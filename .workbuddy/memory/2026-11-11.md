## 补齐交互与动效（同日第二轮）
- 用户质疑「没有交互/鼠标/点击/背景动效不算高级」，补齐全套动效运行时。
- `build_pages.ts` 新增 `MOTION_CSS` + `MOTION_JS`，由 `tpl()` 注入每个模板；`galleryRuntime` 增加 pt-card spotlight、卡片入场 stagger、以及「暂停动效」跨 iframe 同步（`applyMotion` / `watchMotion`）。
- 能力：鼠标柔光跟随、按钮磁吸 + 涟漪、3D tilt、hover 缩放/微抬、区块入场、KPI 数字递增、滚动进度条、tab/分页互斥、行选中、搜索实时筛选（含 table tr）、无处理器按钮 toast、噪点纸感 + 双光斑漂移 + 首屏网格滚动。
- 关键决策：
  - 缩略图 iframe 通过 `getComputedStyle(frameElement).transform` 检测 `matrix(0.25...)` 加 `fx-thumb` 并提前 return，避免 24 个文档同时跑 rAF/动画。
  - 首屏元素用 `fx-reveal-soft`（只位移不改 opacity），否则首帧/截图会停在半透明；滚动进入的元素才用完整淡入。
  - 数字递增加 1.5s `setTimeout` 兜底恢复原文案，避免 rAF 时间不推进时卡在中间值。
  - 背景光斑用 JS 读原 `backgroundImage` 后拼接叠加层，不覆盖模板原背景。
- 验证：24 个模板内 29 段 inline script 全部语法通过；深色/浅色页截图正常；端到端 DOM 测试通过（motion/bgdrift/progress/cursor/tabOn/rowOn/ripple/tilt/reveal/toast/paused/num/表格筛选 4 行淡出 3 行）；主页面交互回归通过；391 卡片完好。

## 页面模板交互再强化（同日第四轮）
- 用户追问「页面模版的那些交互呢？鼠标？动效？粒子？多卡片？？」—— 上一轮把「多搜索」理解成搜索增强，跑偏了；真正关心的是模板本身够不够"活"。
- 关键洞察：之前把缩略图 iframe 完全降级为静态（`fx-thumb` 直接 return），用户在列表页看不到任何动效。
- 改动：
  - **列表可见动效**：缩略图默认静置（不建 canvas / 不跑循环）；主页面 `ptGrid` mouseover/mouseout 向 iframe `documentElement` 注入/移除 `fx-active`；iframe 内 MutationObserver 监听 class，激活时按需创建粒子 canvas 并启动动画，离开即停。CSS 从 `.fx-thumb *{animation:none}` 通配改为只禁用已知无限动画元素，减少 30 个文档的样式计算。
  - **粒子**：canvas 漂浮点 + 近距连线（深色页更亮），25fps `setTimeout` 驱动（不用 rAF：headless 虚拟时间会被无限 rAF 卡住），去掉 `shadowBlur` 改双层圆点模拟光晕。
  - **多卡片**：`.fx-cardwave` 错落入场（`--fx-i` 延迟，动画只改 transform / 不改 opacity，避免首帧内容消失）；`.fx-focus` hover 焦点让同组兄弟退让；每类 +1 共新增 6 个卡片密集页面（峰会报名 / 项目组合 / 商品对比 / 课程列表 / 设计系统文档 / 天气 App），总计 30 个模板。
  - **鼠标**：跟随光标环（遇可交互元素放大）、磁吸 10px、tilt ±5°、涟漪 .22；`fx-hovered` class 让反馈不依赖 CSS `:hover`（程序性 dispatch 也可见）。
- 踩坑：`MOTION_JS` 是注入浏览器的**纯 JS 字符串**，误写 `var pc:any=null` 会让整个 IIFE 语法错误（TS 注解不能出现在 JS 字符串里）；已修复并用 awk 检查该区间无残留 TS 语法。
- 验证：30 模板 / 36 段 inline script 语法通过；最小主页面加载 2.4s；fx2-test 全通过（30 卡 / hover 激活 / 粒子 / 联动 / tilt / 暂停）；reg / mot / modal / search-mini 回归通过；截图确认 6 张商品卡全显示、粒子可见、列表 30 卡完整。
- 备注：复杂长脚本 `gs-test.html` 在 headless `--virtual-time-budget` 下会卡住（页面视图切换 + 大量 iframe 加载的组合），属测试工具限制；已用多个精简测试覆盖同一批能力。
